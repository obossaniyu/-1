
# Паспорт программного модуля

| Характеристика | Описание |
|---|---|
| Название | Расписание занятий |
| Версия | 1.0 |
| Язык программирования | Python 3 |
| Назначение | Управление расписанием занятий |
| Интерфейс | Консольный |
| Формат хранения | JSON |
| Тестирование | pytest |
| Количество unit-тестов | 15 |

## Функциональные возможности

- Добавление занятий.
- Просмотр расписания.
- Редактирование занятий.
- Удаление занятий.
- Проверка конфликтов времени.
- Проверка занятости аудиторий.
- Сохранение и загрузка данных.
- Обработка исключений.

## Руководство пользователя

Для запуска программы необходимо выполнить команду:

`python lab10.py`

После запуска отображается меню:

1. Добавить занятие.
2. Показать расписание.
3. Редактировать занятие.
4. Удалить занятие.
0. Выход из программы.

Для добавления занятия необходимо указать название,
день недели, время начала, время окончания и аудиторию.

Время вводится в формате ЧЧ:ММ.

При пересечении занятий по времени программа
выводит сообщение об ошибке.

Расписание предназначено для одной учебной группы.

Данные автоматически сохраняются в файл schedule.json.

## Тестирование

Для установки pytest:

`python -m pip install pytest`

Для запуска тестирования:

`python -m pytest test_lab10.py -v`

Предусмотрено 15 автоматических тестов, проверяющих
CRUD-операции, конфликты времени и аудиторий,
сохранение и загрузку данных, обработку ошибок.
