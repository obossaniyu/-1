## Функциональные возможности

- Добавление товаров.
- Просмотр списка товаров.
- Редактирование товаров.
- Удаление товаров.
- Сохранение и загрузка данных.
- Формирование отчётов.
- Обработка исключений.

## Руководство пользователя

Для запуска программы необходимо выполнить команду:

`python lab10.py`

После запуска отображается меню:

1. Добавить товар.
2. Показать товары.
3. Редактировать товар.
4. Удалить товар.
5. Сформировать отчёт.
0. Выход из программы.

Для добавления товара необходимо указать название, цену и количество. Данные автоматически сохраняются в файл products.json.

Для формирования отчёта необходимо выбрать пункт 5. Программа рассчитает количество видов товаров, общее количество единиц и суммарную стоимость.

## Тестирование

Для установки pytest:

`python -m pip install pytest`

Для запуска тестирования:

`python -m pytest test_lab10.py -v`

Предусмотрено 15 автоматических тестов, проверяющих основные операции, сохранение и загрузку данных, расчёт отчётов и обработку ошибок.
